Modelo para novos posts. Copie este arquivo, renomeie (o nome vira a URL: `meu-post.md` → `/blog/meu-post/`),
ajuste o frontmatter e troque `draft: true` por `draft: false` (ou apague a linha) para publicar.

Rascunhos aparecem só no `npm run dev`, marcados como "rascunho".

## Subtítulo

Texto com **negrito**, *itálico*, [links](https://astro.build) e `código inline`.

```js
console.log('blocos de código têm destaque de sintaxe');
```
